# Hangman - משחק האיש התלוי
# תאור הפרויקט

משחק אינטראקטיבי של "האיש התלוי" אשר כולל צד שרת ו"צד לקוח" מבוסס סקריפטים בפייתון.
המשחק מאפשר למשתמש לנחש מילה נסתרת תוך שמירה על סטטוס המשחק לאורך זמן באמצעות cookies, ניהול שגיאות חכם וכתיבה לקבצים. 

# יכולות עיקריות

ניהול session אישי לכל משתמש באמצעות cookie.

ניהול מלא של מהלך משחק (מילה, ניחושים, סטטוס) על בסיס בקשות HTTP.

כתיבת היסטוריית המשחקים לקובץ לצורך תיעוד.

קריאה אוטומטית של רשימת מילים מתוך קובץ.

זריקת שגיאות מהשרת באמצעות מחלקת שגיאה מותאמת אישית היורשת מ־Exception.

# ארכיטקטורת הפרויקט

צד שרת (Flask):

ניהול בקשות GET/POST למשחק.

אחסון סטטוס המשחק בזיכרון לכל session.

טיפול בשגיאות באמצעות מחלקה מותאמת המרחיבה את Exception.

קריאה של מילים מקובץ לצורך בחירת המילה.

כתיבה לקובץ של תוצאות המשחק או שגיאות בהתאם לצורך.

צד לקוח (סקריפט Python):

שימוש בספריית requests לשליחת בקשות לשרת.

שמירת cookie לצורך המשכיות המשחק.

קבלת תגובות מהשרת והדפסת סטטוס עדכני של המשחק למשתמש.

טיפול בזרימת המשחק בהתאם לתשובות מהשרת.

# טכנולוגיות בשימוש

Python 3

Flask – שרת HTTP פשוט ויעיל

requests – שליחת בקשות HTTP מהלקוח

cookies – שמירת מידע מצב בצד הלקוח

קבצים (txt/json) – קריאה של מילים וכתיבת לוגים

מחלקת חריגות מותאמת אישית – לניהול שגיאות בצורה תקינה
